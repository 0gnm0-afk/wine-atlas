# Wine Atlas

▶ 웹에서 바로 사용하기: [https://0gnm0-afk.github.io/wine-atlas/](https://0gnm0-afk.github.io/wine-atlas/)

와인 라벨에서 본 산지명을 검색해 67개 산지의 대표 위치, 환경, 주요 포도와 와인 성격을 살펴보는 정적 지도입니다. GitHub Pages에서 별도 서버나 로그인 없이 동작합니다.

## 공개 데이터 범위

- 화면에 표시하는 67개 산지의 이름·검색 별칭·근사 대표점
- 지도 표시를 위한 공개 지형 도형과 개략 분포 그림
- 위치·환경·주요 포도·와인 성격에 관한 편집 설명
- 각 설명에서 참고한 공개 외부 자료의 제목·발행처·URL

공개 데이터는 명시적인 필드 허용 목록으로 생성합니다. 작품 원문·인용·등장 근거·화 번호, 내부 분석, 비공개 원본, 작업 메타데이터와 로컬 경로는 저장소 및 배포 산출물에 포함하지 않습니다.

## 개인정보와 사진

‘와인 뒷라벨 촬영’에서 후면 카메라 또는 사진 선택 → 미리보기 → 글자 읽기 → 원문 수정을 제공합니다. 사진·OCR 문자열·검색 기록은 서버나 분석 도구로 전송하지 않으며 로그·브라우저 영구 저장소에 보관하지 않습니다. 취소·닫기·페이지 이탈 시 사진과 결과를 지우고 Worker를 종료합니다. 단말의 사진 앱이 보관하는 원본은 이 사이트의 관리 범위 밖입니다.

OCR은 Tesseract.js 7.0.0, core 7.0.0, tessdata_fast의 영어·한국어 모델을 사용합니다. Worker·WASM·모델은 모두 이 사이트에서 제공하며 ‘글자 읽기’를 누를 때만 약 8.9MB를 내려받습니다. 첫 사용에는 네트워크 연결이 필요하고, 다운로드 속도와 단말 성능에 따라 시간이 달라집니다. 모델의 IndexedDB 캐시는 사용하지 않습니다. 공개 정적 도구 파일은 일반 HTTP 캐시에 남을 수 있지만 사진과 인식 결과는 저장하지 않습니다.

20MB·4,800만 화소 이하 사진을 지원하며 브라우저가 지원하지 않는 형식은 JPG/PNG로 변환해 선택합니다. EXIF 방향을 반영하고 Canvas로 긴 변을 2,000px 이하로 줄입니다. 카메라 선택 화면은 운영체제에 따라 다르므로 별도 ‘사진 선택’ 버튼도 제공합니다. OCR에는 오인식과 악센트 누락이 있을 수 있습니다. 인식 후 67개 공개 산지를 자동 검색합니다. 정확히 하나가 읽히면 지도와 상세를 열고, 여러 이름이나 오타 후보는 최대 3개 중 직접 선택합니다. 글자를 수정한 뒤에는 OCR을 다시 실행하지 않고 검색만 합니다.

## 실행

`site/`를 정적 HTTP 서버로 제공하면 됩니다. `main` 브랜치 갱신 시 `.github/workflows/pages.yml`이 공식 GitHub Pages Actions로 같은 폴더를 자동 배포합니다. 모든 앱 경로는 저장소 프로젝트 경로에서 동작하도록 상대 경로입니다.

## 공개 데이터 재생성

관리자는 비공개 원천 프로젝트에서 다음 순서로 공개 저장소 사본을 다시 만듭니다.

1. `scripts/build_region_atlas.py --require-complete`로 원천 무결성을 확인합니다.
2. `scripts/build_public_atlas.py`로 허용 목록에 있는 파일과 필드만 `atlas/public-repo/`에 생성합니다.
3. `scripts/check_public_bundle.py`로 파일 목록, 67개 산지 스키마, 금지 필드, 로컬 경로, 비밀정보와 소스맵 부재를 검사합니다.
4. 생성 폴더의 바이트 차이를 검토한 뒤 이 공개 저장소에 반영합니다.

생성기는 시각이나 임의 값에 의존하지 않으므로 같은 입력에서 같은 파일을 만듭니다. 원천 자료는 공개 저장소로 복사하지 않습니다.

출력은 `public-repo`라는 생성 전용 폴더로 제한됩니다. 기존 출력에 `.git`·추가 파일·추가 폴더·파일시스템 링크가 있으면 중단하며, 출력 폴더를 재귀 삭제하지 않습니다. 검토한 사본을 별도 Git 저장소에 반영합니다. 검사기는 모든 공개 텍스트의 금지 데이터와 데이터의 말단 자료형까지 확인합니다. 화면에 표시하지 않는 다섯 번째 이후 특징과 중복 묘사는 제외하며, 지도 확대 동작에는 공개 산지 사이의 최소 표시 관계만 사용합니다.

직접 작성한 코드에는 [MIT License](LICENSE)의 코드 범위 조항이 적용됩니다. 편집 설명과 파생 데이터는 별도 허락이 없는 한 재사용 권리를 부여하지 않습니다. Leaflet과 Natural Earth를 포함한 외부 자원은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 정리했습니다.

지도 색 면은 산지를 찾기 위한 개략 분포 그림이며 공식 아펠라시옹 경계가 아닙니다. 점도 공식 경계·필지 좌표가 아닌 근사 대표 위치입니다.

## 산지 검색과 추가 요청

검색 인덱스는 공개 ID·표시명·영문명·현지명·검토된 별칭만 포함합니다. 악센트·대소문자·문장부호·공백을 정규화하고 단어 경계에서 일치시킵니다. 정확한 결과가 없을 때만 자체 호스팅한 Fuse.js **7.1.0 basic build (Apache-2.0)**로 비슷한 이름을 제안합니다. 국가명이나 일반 단어만으로 산지를 확정하지 않습니다. 긴 문장은 처음 12,000자, 유사 검색은 최대 350단어를 확인합니다.

결과가 없으면 수정·재촬영하거나 OCR 문장을 복사하고 [산지 추가 요청](https://github.com/0gnm0-afk/wine-atlas/issues/new?template=region-request.yml)으로 이동할 수 있습니다. 수정했다면 현재 수정된 문장을 복사합니다. GitHub 로그인이 필요하며, 제출한 글과 사진은 공개됩니다. 앱은 OCR을 링크에 넣거나 사진을 자동 업로드하지 않습니다. 사용자가 GitHub 화면에서 직접 붙여넣거나 사진을 선택적으로 첨부합니다. Issue를 만들어도 산지 데이터는 자동으로 바뀌지 않습니다.
