# Wine Atlas — 라벨을 찍으면 산지를 찾아주는 와인 지도

마트나 와인숍에서 와인 뒷라벨을 촬영하면 글자를 읽어 산지 후보를 찾고, 해당 산지의 위치·환경·주요 포도·와인 성격을 지도에서 보여주는 모바일 웹 도구입니다.

사진과 OCR 결과는 외부 서버로 보내지 않고 브라우저 안에서 처리합니다.

▶ **[Wine Atlas 바로 사용하기](https://0gnm0-afk.github.io/wine-atlas/)**

> 라벨의 낯선 지명을 실제 장소와 연결해, 한 병의 와인이 어디에서 왔고 왜 그런 성격을 갖는지 이해하려고 만들었습니다.

## 프로젝트를 시작한 이유

이 프로젝트는 문피아 웹소설 [『와인의 신』](https://nlink.munpia.com/link/munpia/novel/494781)에 등장하는 와인 산지를 정리하면서 시작했습니다.

소설을 읽다 보니 나파 밸리, 보르도, 부르고뉴처럼 익숙한 이름뿐 아니라 오크빌, 포므롤, 몽라셰처럼 더 세부적인 산지가 계속 등장했습니다. 이름을 목록으로만 정리하는 것보다, 실제로 어디에 있고 상위·하위 산지가 어떻게 연결되는지 지도에서 보고 싶었습니다.

정리를 계속하면서 실제 생활에서의 불편도 발견했습니다.

마트에서 와인을 고를 때 라벨에 적힌 산지명을 보더라도, 그곳이 어느 나라의 어떤 지역인지, 어떤 포도와 와인으로 알려져 있는지 바로 떠올리기 어려웠습니다. 작은 글자를 직접 입력하거나 검색 결과 여러 개를 오가는 대신, 휴대전화로 뒷라벨을 찍으면 산지를 찾아 바로 설명을 보여주는 도구를 만들고 싶었습니다.

처음에는 산지명을 직접 검색하는 지도로 시작했고, 현재는 다음 흐름을 모바일 브라우저에서 사용할 수 있도록 확장했습니다.

```text
와인 뒷라벨 촬영
→ 브라우저에서 글자 인식
→ 공개 산지 데이터와 대조
→ 산지 후보 확인
→ 지도와 산지 설명 열기
```

## 사용 방법

1. 모바일 브라우저에서 Wine Atlas를 엽니다.
2. `와인 뒷라벨 촬영`을 누릅니다.
3. 후면 카메라로 라벨을 찍거나 기존 사진을 선택합니다.
4. 미리보기를 확인한 뒤 `글자 읽기`를 누릅니다.
5. 읽은 글자가 틀렸다면 직접 수정합니다.
6. 정확히 일치하는 산지가 하나면 해당 지도를 바로 엽니다.
7. 여러 산지 또는 비슷한 이름이 발견되면 최대 3개의 후보 중 직접 선택합니다.

카메라를 사용하지 않고 한글명·영문명·별칭을 직접 입력하거나 목록에서 산지를 선택할 수도 있습니다.

| 후보 제시 | 여러 산지나 오타 후보를 최대 3개까지 표시 |
| 직접 검색 | 한글명·영문명·현지명·검토된 별칭 검색 |

| 세부 산지 탐색 | 보르도·부르고뉴·나파 밸리 등 계층 관계와 확대 보기 |
| 산지 설명 | 위치·환경·주요 포도·와인에서 기억할 점 제공 |
| 출처 확인 | 설명 작성에 참고한 외부 자료 연결 |
| 미등록 산지 요청 | OCR 문자열을 복사해 GitHub Issue로 검토 요청 |

## 산지를 찾는 방식

OCR이 읽은 전체 문장을 그대로 검색 서비스에 보내지 않습니다. 브라우저 안에서 공개 산지 데이터와 대조합니다.

### 1. 정확한 이름을 먼저 찾습니다

한글명, 영문명, 현지명과 검토된 별칭을 정규화해 검색합니다.

- 대소문자 차이
- 악센트 유무
- 공백과 문장부호 차이
- 한글·영문 표기 차이

를 정리한 뒤, 문장 안에서 산지명이 단어 단위로 나타나는지 확인합니다.

`Rioja Alta`가 읽혔을 때 더 짧은 `Rioja`까지 중복 선택되지 않도록, 긴 이름이 짧은 이름을 포함하면 더 구체적인 산지를 우선합니다.

### 2. 일반 단어만으로 산지를 확정하지 않습니다

`France`, `Wine`, `Estate`, `Winery`, `Reserve`처럼 라벨에 자주 등장하지만 특정 산지를 가리키지 않는 표현은 산지 확정 근거로 사용하지 않습니다.

국가명이나 일반적인 와인 용어만 읽혔다는 이유로 임의의 산지를 열지 않습니다.

### 3. 정확한 결과가 없을 때만 비슷한 이름을 제안합니다

정확한 이름을 찾지 못하면 Fuse.js를 사용해 OCR 오타와 유사한 산지명을 탐색합니다.

유사 검색 결과는 정답으로 자동 확정하지 않습니다. 최대 3개의 후보를 보여주고, 사용자가 실제 라벨과 비교해 직접 선택하도록 합니다.

```text
정확한 산지 1개
→ 해당 산지 바로 열기

정확한 산지 여러 개
→ 사용자가 원하는 산지 선택

비슷한 이름만 발견
→ 후보를 라벨과 대조한 뒤 선택

일치 결과 없음
→ 글자 수정·재촬영·산지 추가 요청
```

## 사진과 개인정보 처리

라벨 사진과 OCR 문자열은 이 사이트의 서버나 외부 OCR 서비스로 전송하지 않습니다.

- 사진은 브라우저 메모리에서만 처리합니다.
- OCR은 사이트에 포함된 Tesseract.js Worker에서 실행합니다.
- 사진·OCR 문자열·검색 기록을 분석 도구로 전송하지 않습니다.
- 브라우저의 영구 저장소에 사진이나 인식 결과를 보관하지 않습니다.
- 촬영 화면을 닫거나 취소하거나 페이지를 벗어나면 사진과 결과를 지웁니다.
- OCR 작업을 취소하거나 화면을 닫으면 Worker를 종료합니다.
- 산지 추가 요청을 열어도 사진이나 OCR 문자열을 GitHub로 자동 전송하지 않습니다.

기기의 사진 앱이 원본 사진을 저장하는지는 운영체제와 사용자의 카메라 설정에 따르며 Wine Atlas의 관리 범위에 포함되지 않습니다.

처음 `글자 읽기`를 실행하면 사이트에서 OCR Worker·WASM·영어 및 한국어 모델 약 8.9MB를 내려받습니다. 공개 OCR 도구 파일은 일반적인 브라우저 HTTP 캐시에 남을 수 있지만, 촬영한 사진과 OCR 결과는 캐시하지 않습니다.

## 사진 입력 처리

- 최대 20MB의 이미지 파일을 받습니다.
- 최대 4,800만 화소까지 확인합니다.
- EXIF 방향을 반영해 이미지를 표시합니다.
- OCR 전 긴 변을 최대 2,000px로 축소합니다.
- JPG·PNG·WebP처럼 브라우저가 읽을 수 있는 사진을 사용할 수 있습니다.
- 카메라 선택 화면과 지원 형식은 운영체제와 브라우저에 따라 달라질 수 있습니다.

OCR에는 오인식과 악센트 누락이 생길 수 있습니다. 인식된 글자를 바로 확정값으로 사용하지 않고 수정 가능한 원문과 산지 후보를 함께 보여주는 이유입니다.

## 지도에서 확인할 수 있는 정보

산지를 선택하면 다음 정보를 한 화면에서 확인할 수 있습니다.

| 정보 | 목적 |
|---|---|
| 한글명·영문명·현지명 | 라벨의 여러 표기를 연결 |
| 위치 계층 | 국가·광역 산지·세부 산지의 관계 확인 |
| 지도 위치 | 이름으로 알던 산지를 실제 장소와 연결 |
| 환경과 산지 특징 | 기후·지형·토양의 배경 확인 |
| 주요 포도 | 해당 산지에서 자주 만나는 품종 확인 |
| 와인에서 기억할 점 | 산지를 처음 접할 때 기억할 핵심 정리 |
| 자료 출처 | 더 자세한 내용과 근거 확인 |

Wine Atlas의 지도 점은 공식 경계나 개별 포도밭 좌표가 아닌 근사 대표 위치입니다. 색으로 표시한 면도 산지를 찾기 위한 개략적인 분포이며 공식 아펠라시옹 경계를 의미하지 않습니다.

산지 설명은 일반적인 경향입니다. 실제 와인은 빈티지, 생산자, 포도밭과 양조 방식에 따라 달라질 수 있습니다.

## 미등록 산지 요청

OCR 결과에서 산지를 찾지 못했다면 다음 순서로 다시 확인할 수 있습니다.

1. 읽힌 글자를 직접 수정합니다.
2. 더 밝고 선명한 사진으로 다시 촬영합니다.
3. OCR 문장을 복사합니다.
4. [산지 추가 요청](https://github.com/0gnm0-afk/wine-atlas/issues/new?template=region-request.yml)을 작성합니다.

산지 추가 요청은 GitHub 로그인이 필요하며 Issue 내용과 첨부 사진은 공개됩니다. 앱은 OCR 문자열이나 사진을 Issue에 자동으로 넣지 않습니다. 사용자가 공개 여부를 확인한 뒤 직접 붙여넣거나 선택적으로 사진을 첨부합니다.

요청이 접수돼도 산지 데이터가 자동 변경되지는 않습니다. 운영자가 산지명·위치·설명과 출처를 검토한 뒤 반영합니다.

## 기술 구성

| 구성 | 역할 |
|---|---|
| HTML·CSS·JavaScript | 모바일 화면, 검색, 촬영 흐름과 산지 상세 표시 |
| Tesseract.js 7.0.0 | 브라우저 내부 영어·한국어 OCR |
| Fuse.js 7.1.0 | 정확한 검색 실패 후 오타 후보 제안 |
| Leaflet 1.9.4 | 지도 이동·확대와 산지 표시 |
| Natural Earth | 기본 지형·경계·하천 데이터 |
| 정적 데이터 번들 | 산지명·별칭·위치·설명·출처 제공 |
| GitHub Pages | 별도 서버 없는 정적 웹 배포 |
| GitHub Actions | `main` 브랜치 갱신 시 자동 배포 |

OCR과 유사 검색에 필요한 실행 파일도 사이트에서 직접 제공합니다. CDN이나 클라우드 OCR API를 호출하지 않습니다.

## 현재 범위와 한계

Wine Atlas는 등록된 67개 산지를 찾고 이해하기 위한 도구입니다.

- 등록되지 않은 생산자명이나 와인 상품명을 식별하지 않습니다.
- 라벨 전체를 해석하거나 와인의 품질을 평가하지 않습니다.
- 구매 적합성이나 와인 추천 결과를 제공하지 않습니다.
- OCR 정확도는 사진의 밝기·초점·글자 크기·라벨 디자인에 영향을 받습니다.
- 비슷한 산지명이 여러 개 있으면 사용자의 확인이 필요합니다.
- 산지 OCR 정확도와 후보 선택률을 정량 평가한 결과는 아직 없습니다.
- 모든 모바일 기기와 브라우저 조합에서의 동작을 보장하지 않습니다.

다음 검증에서는 실제 라벨 사진 표본을 모아 다음을 확인하려 합니다.

- 등록 산지명이 OCR 문자열에 포함되는 비율
- 정확한 산지를 첫 번째 후보로 제시하는 비율
- 오인식된 라벨에서 잘못된 산지를 자동 확정하지 않는지
- 촬영부터 산지 상세 화면까지 걸리는 시간
- 사용자가 원문 수정이나 재촬영을 필요로 하는 빈도
- 서로 다른 모바일 브라우저에서의 촬영·취소·메모리 정리 동작

## 프로젝트의 변화

| 초기 버전 | 현재 버전 |
|---|---|
| 소설에 등장한 산지를 목록으로 정리 | 67개 산지를 지도와 계층 구조로 탐색 |
| 사용자가 산지명을 직접 입력 | 뒷라벨 촬영과 브라우저 OCR 지원 |
| 이름이 정확히 일치해야 검색 | 표기 정규화와 유사 후보 제안 |
| 산지 검색 결과만 표시 | 위치·환경·주요 포도·와인 성격과 출처 제공 |
| 등록된 데이터만 사용 | 미등록 산지의 공개 검토 요청 경로 제공 |

기능을 추가하면서도 OCR 결과를 정답으로 자동 확정하거나, 사진을 외부 서비스에 보내 편의성을 높이는 방식은 선택하지 않았습니다. 사용자가 읽힌 원문과 후보를 확인할 수 있고, 결과가 없을 때 수정·재촬영·추가 요청으로 이어질 수 있도록 구성했습니다.

## 로컬 실행

별도의 패키지 설치나 API 키는 필요하지 않습니다.

```bash
git clone https://github.com/0gnm0-afk/wine-atlas.git
cd wine-atlas
python -m http.server 8000 -d site
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

카메라 접근은 브라우저 보안 정책에 따라 HTTPS 또는 `localhost` 환경에서 사용하는 것을 권장합니다.

## 공개 데이터와 저작권

공개 저장소에는 웹사이트에 필요한 산지명, 검색 별칭, 근사 대표 위치, 편집 설명과 외부 자료 링크만 포함합니다.

프로젝트의 출발점이 된 작품의 원문, 직접 인용, 등장 화차와 비공개 작업 기록은 공개 데이터에 포함하지 않습니다. 산지 설명은 공개 외부 자료와 별도로 정리한 내용을 바탕으로 작성했으며, 각 산지 화면에서 관련 출처를 확인할 수 있습니다.
